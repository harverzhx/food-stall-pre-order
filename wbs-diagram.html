WORK BREAKDOWN STRUCTURE (WBS)

1.0
Project Management & Planning
1.1 Define project scope & objectives
1.2 Identify Stakeholders & Users
1.3 Gather Initial Requirements
1.4 Develop Project Schedule & Risk Plan
2.0
System Design
2.1 Design system architecture
2.2 Design Database Schema (ERD)
2.3 Design UI/UX Wireframes (Figma)
2.4 Design Order & Payment Workflow
3.0
System Development
3.1 Develop User Auth & Profiles
3.2 Develop Customer App (Pre-Order & Menu)
3.3 Develop Vendor Dashboard (Stock & Sales)
3.4 Develop Back-End APIs & Database Connect
4.0
System Testing & QA
4.1 Prepare Test Cases & Plan
4.2 Conduct Unit & System Testing
4.3 Conduct QR / Order Scanning Tests
4.4 Perform User Acceptance Testing (UAT)
5.0
Deployment & Implementation
5.1 Prepare Production Environment
5.2 Deploy App & Database (Cloud Host)
5.3 Vendor Onboarding & Training
5.4 Launch App to Students & Campus
6.0
Documentation & Project Closure
6.1 Prepare Technical & User Manuals
6.2 Conduct Final Presentation / Demo
6.3 Turn Over System to School Canteen
6.4 Obtain Final Project Acceptance
